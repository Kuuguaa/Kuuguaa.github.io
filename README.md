# 个人品牌网站 · 使用说明

纯原生 HTML / CSS / JavaScript，零依赖、零构建，不需要安装任何开发环境。

## 文件结构

```
site/
├── index.html      # 页面内容（所有文案都在这里改）
├── styles.css      # 样式（像素游戏风 · 绿色蔬菜主题）
├── script.js       # 滚动渐入动画（可删，不影响内容显示）
├── images/
│   ├── avatar.png        # 头像（替换同名文件即可换图）
│   └── sprite-*.svg      # 像素蔬菜装饰图（苦瓜/黄瓜/嫩芽/叶子）
├── tools/
│   └── make_sprites.py   # 像素画生成脚本（改了字符图重跑即可，可选）
└── README.md
```

## 电脑上预览

方式一（最简单）：双击 `index.html`，用浏览器打开即可。

方式二（推荐，路径行为与线上一致）：在本文件夹启动一个本地服务——

- 装了 Python：命令行进入本文件夹，运行 `python -m http.server 8000`，浏览器访问 `http://localhost:8000`
- 装了 Node：运行 `npx serve .`，按提示访问对应地址

## 检查手机效果

电脑浏览器按 `F12` 打开开发者工具，点工具栏上的"设备模拟"图标（或按 `Ctrl+Shift+M`），选择 iPhone / 任意安卓机型即可模拟手机宽度。真正的验收标准：用自己的手机打开。

## 发布到 GitHub Pages（免费）

1. 注册/登录 GitHub，新建一个公开仓库，名为 `你的用户名.github.io`。
2. 把本文件夹里的**所有文件**（不含 README 也可以）上传到仓库根目录：
   - 不会用 Git 的话，直接在仓库页面点 `Add file → Upload files`，拖进去提交即可。
3. 仓库 `Settings → Pages`，Source 选择 `main` 分支、`/ (root)` 目录，保存。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io` 就能看到网站。

以后改内容：在仓库里直接编辑 `index.html` 或重新上传文件，几分钟后自动生效。

## 上线前必须替换的【待确认】

在 `index.html` 里搜索 `【待确认`，逐项替换为真实信息（称呼、微信号、咨询方式/时长/费用/城市、账号名）。公益项目经历默认未展示（代码中有注释），确认要展示再取消注释。
